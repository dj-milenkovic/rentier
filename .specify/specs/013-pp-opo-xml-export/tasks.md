## Phase 3: User Story 1 — Export a Filing as PP-OPO XML File (Priority: P1) 🎯 MVP

**Goal**: A user clicks "Export" on a filing row; the handler loads the filing, taxpayer profile, and importer payment notes; the serializer produces a valid PP-OPO XML byte array; a native save dialog pre-populated with `PP-OPO_YYYY-MM_JMBG.xml` lets the user choose a path; the file is written to disk asynchronously.

**Independent Test**: Load a fixture filing with known field values, trigger `ExportCommand.Execute(filingId)`, verify that the result is `IsSuccess = true`, `result.Value.Bytes` parses as a well-formed XML document with root element `PodaciOPrijavi`, and `result.Value.SuggestedFileName` matches the expected `PP-OPO_{period}_{jmbg}.xml` pattern.

### Application — Handler

- [ ] T005 [P] [US1] Implement `ExportFilingCommandHandler` in `src/Rentier.Application/Handlers/ExportFilingCommandHandler.cs` as `public sealed class ExportFilingCommandHandler : ICommandHandler<ExportFilingCommand, Result<ExportFilingResult, Error>>`; constructor injects `IFilingRepository filingRepository`, `IReportRepository reportRepository`, `IImporterRepository importerRepository`, `ITaxpayerProfileRepository profileRepository`, `IXmlFilingSerializer serializer`; implement `HandleAsync` with the following loading chain:
  1. `var filing = await _filingRepo.GetByIdAsync(command.FilingId, ct)` — if null: `return Result<ExportFilingResult, Error>.Failure(Error.NotFound("Filing not found."))`
  2. `var profile = await _profileRepo.GetAsync(ct)` — if null: `return Result<ExportFilingResult, Error>.Failure(Error.Domain("Taxpayer profile is required before exporting."))`
  3. If `filing.ReportId != null`: `var report = await _reportRepo.GetByIdAsync(filing.ReportId.Value, ct)`; if report != null: `var importer = await _importerRepo.GetByIdAsync(report.ImporterId, ct)`; else importer = null; else skip both repo calls
  4. `var paymentNotes = importer?.PaymentNotes ?? string.Empty`
  5. `var bytes = _serializer.Serialize(filing, profile, paymentNotes)`
  6. `var suggestedName = $"PP-OPO_{filing.IncomeDate:yyyy-MM}_{profile.Jmbg}.xml"`
  7. Return `Result<ExportFilingResult, Error>.Success(new ExportFilingResult(bytes, suggestedName))`
  (depends on T002, T003, T004)
