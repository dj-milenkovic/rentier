# Implementation Plan: Test Coverage Expansion

**Branch**: `042-test-coverage-expansion` | **Date**: 2025-07-15 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/042-test-coverage-expansion/spec.md`

## Summary

Expand test coverage to close three gaps identified in the DevOps analysis: (A) 6+ new FsCheck property-based tests for domain invariants (exchange-rate rounding, filing-status transitions, deadline weekday/holiday avoidance, report-sum consistency, pagination completeness, payment-reference format), (B) 4+ new Verify snapshot tests for serialization stability (XML interest income, XML payment references, IBKR CSV parser output, filing details export), and (C) unit tests for the 3 untested ViewModels (HolidayEntryViewModel, SyncProgressEntryViewModel, ImporterItemViewModel). This is a test-only feature — no production code changes.

## Technical Context

**Language/Version**: C# 14 / .NET 10.0  
**Primary Dependencies**: xUnit 2.x, FluentAssertions 6.x, NSubstitute 5.x, FsCheck.Xunit 3.x (property-based), Verify.Xunit 28.x (snapshots), Avalonia.Headless.XUnit 11.x (UI), CoverletCollector 6.x  
**Storage**: N/A (test-only feature; no database changes)  
**Testing**: xUnit runner with `dotnet test`; FsCheck `[Property]` attribute + `ToProperty()` for PBT; `Verify()` + `.verified.*` baselines for snapshots  
**Target Platform**: Cross-platform (.NET 10.0; CI: GitHub Actions Windows + macOS matrix)  
**Project Type**: Desktop application (Avalonia UI) — test-only changes  
**Performance Goals**: Full test suite completes within existing CI time budget with ≤15% increase  
**Constraints**: No network calls, no filesystem side effects, no database for unit tests; `TreatWarningsAsErrors=true`  
**Scale/Scope**: 13+ new test methods across 3 existing test projects
