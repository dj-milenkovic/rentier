# Implementation Plan: Filings Table Always Visible

**Branch**: `044-filings-table-always-visible` | **Date**: 2025-07-15 | **Spec**: `.specify/specs/044-filings-table-always-visible/spec.md`
**Input**: Feature specification from `.specify/specs/044-filings-table-always-visible/spec.md`

## Summary

Make the filings DataGrid permanently visible on the Filings page regardless of data state. Currently, the DataGrid is hidden (`IsVisible="{Binding HasItems}"`) when no filings exist and replaced by a full-page "No filings found" message. This change removes the visibility binding so column headers always render, relocates the empty-state message to a subtle position below the grid, and ensures stable layout across all page states (loading, empty, populated, error). This is a UI-only change confined to `Rentier.Desktop`.

## Design Decisions

### D-001: Remove DataGrid `IsVisible` Binding

**Current** (line 100 of FilingsView.axaml):
```xml
<DataGrid x:Name="FilingsGrid" ... IsVisible="{Binding HasItems}" ...>
```

**Proposed**: Remove the `IsVisible` attribute entirely. The DataGrid defaults to `IsVisible="True"`.

**Rationale**: Simplest change. The DataGrid already handles an empty `ItemsSource` correctly — it renders column headers with no rows.

### D-002: Relocate Empty-State Message

**Current** (lines 89-94 of FilingsView.axaml):
```xml
<!-- Empty state -->
<TextBlock DockPanel.Dock="Top"
           IsVisible="{Binding IsEmpty}"
           Text="{Binding [Filings_Empty], Source={StaticResource Localizer}}"
           HorizontalAlignment="Center" VerticalAlignment="Center"
           Margin="0,40" />
```
This sits **above** the DataGrid in the DockPanel and visually replaces the table.

**Proposed**: Move the TextBlock to **after** the DataGrid in the DockPanel (making it fill remaining space below/inside the grid area). Restyle with muted appearance:
```xml
<TextBlock IsVisible="{Binding IsEmpty}"
           Text="{Binding [Filings_Empty], Source={StaticResource Localizer}}"
           HorizontalAlignment="Center"
           Foreground="{DynamicResource RentierTextSecondaryBrush}"
           FontSize="13"
           Margin="0,24" />
```

**Rationale**: Positions the hint below the always-visible column headers. Uses existing design system token (`RentierTextSecondaryBrush`) for muted styling per FR-003/FR-004.

### D-003: No ViewModel Logic Changes

The `HasItems` and `IsEmpty` computed properties remain unchanged:
- `HasItems` → still used by select-all checkbox `IsEnabled`
- `IsEmpty` → still used by the relocated empty-state message

No new properties, commands, or reactive pipelines needed.

## Implementation Approach

### Step 1: Modify FilingsView.axaml

1. Remove `IsVisible="{Binding HasItems}"` from the `<DataGrid>` element
2. Move the empty-state `<TextBlock>` from its current position (above DataGrid) to after the DataGrid
3. Restyle the TextBlock: `RentierTextSecondaryBrush`, `FontSize="13"`, reduce margin

### Step 2: Optional — Soften Localization Text

Update `Filings_Empty` in `Strings.resx` from "No filings found." to "No filings yet." and update `SrLatnStrings.cs` accordingly. This is a polish item aligned with User Story 2.

### Step 3: Update Tests

1. **FilingsViewModelTests.cs**: Run existing `IsEmpty_WhenNoRows_IsTrue` and `IsEmpty_WhenRowsPresent_IsFalse` tests — no changes expected.
2. **FilingsViewHeadlessTests.cs**: Add test verifying DataGrid is visible (`IsVisible == true`) when ViewModel has zero rows.
