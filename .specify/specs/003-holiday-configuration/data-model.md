## Domain Entities

### `PublicHoliday`

**File**: `src/Rentier.Domain/Entities/PublicHoliday.cs`  
**Layer**: Domain  
**Purpose**: Represents a single public holiday date with its name, persisted to SQLite.

```csharp
// src/Rentier.Domain/Entities/PublicHoliday.cs
namespace Rentier.Domain.Entities;

public sealed class PublicHoliday
{
    public Guid Id { get; private set; }
    public DateOnly Date { get; private set; }
    public string Name { get; private set; }
    public int Year { get; private set; }        // = Date.Year, stored for query efficiency

    // Private parameterless constructor for EF Core materialisation
    private PublicHoliday() { }

    private PublicHoliday(Guid id, DateOnly date, string name)
    {
        if (string.IsNullOrWhiteSpace(name))
            throw new DomainException("Holiday name must not be empty.");

        Id = id;
        Date = date;
        Name = name;
        Year = date.Year;
    }

    public static PublicHoliday Create(DateOnly date, string name)
        => new(Guid.NewGuid(), date, name);
}
```

**Field Summary**:

| Field | Type | Constraints |
|-------|------|-------------|
| `Id` | `Guid` | PK; generated by `Guid.NewGuid()` at creation |
| `Date` | `DateOnly` | Stored as TEXT `"yyyy-MM-dd"` in SQLite (EF Core 8 native) |
| `Name` | `string` | NOT NULL; maxLength 200; must not be empty/whitespace |
| `Year` | `int` | Computed from `Date.Year`; stored for indexed queries |

### `HolidayYearRange`

**File**: `src/Rentier.Domain/Entities/HolidayYearRange.cs`  
**Layer**: Domain  
**Purpose**: Singleton record (Id=1) defining the active year window for holiday display and
deadline calculation. Domain validates the range on construction.

```csharp
// src/Rentier.Domain/Entities/HolidayYearRange.cs
namespace Rentier.Domain.Entities;

public sealed class HolidayYearRange
{
    public const int SingletonId = 1;
    public const int MinStartYear = 2020;
    public const int MaxYearSpan = 10;

    public int Id { get; private set; }
    public int StartYear { get; private set; }
    public int EndYear { get; private set; }

    // Private parameterless constructor for EF Core materialisation
    private HolidayYearRange() { }

    public HolidayYearRange(int startYear, int endYear)
    {
        if (startYear < MinStartYear)
            throw new DomainException($"StartYear must be >= {MinStartYear}.");
        if (endYear > startYear + MaxYearSpan)
            throw new DomainException($"EndYear must be <= StartYear + {MaxYearSpan}.");
        if (endYear < startYear)
            throw new DomainException("EndYear must be >= StartYear.");

        Id = SingletonId;
        StartYear = startYear;
        EndYear = endYear;
    }
}
```

**Field Summary**:

| Field | Type | Constraints |
|-------|------|-------------|
| `Id` | `int` | PK; always 1 (singleton) |
| `StartYear` | `int` | >= 2020; NOT NULL |
| `EndYear` | `int` | <= StartYear + 10; >= StartYear; NOT NULL |

**Validation Rules** (enforced in Domain, throws `DomainException`):
- `StartYear >= 2020`
- `EndYear >= StartYear`
- `EndYear <= StartYear + 10`

## EF Core Configuration

### `PublicHolidayConfiguration`

**File**: `src/Rentier.Infrastructure/Persistence/Configurations/PublicHolidayConfiguration.cs`

```csharp
namespace Rentier.Infrastructure.Persistence.Configurations;

internal sealed class PublicHolidayConfiguration : IEntityTypeConfiguration<PublicHoliday>
{
    public void Configure(EntityTypeBuilder<PublicHoliday> builder)
    {
        builder.ToTable("PublicHolidays");
        builder.HasKey(h => h.Id);
        builder.Property(h => h.Name)
               .IsRequired()
               .HasMaxLength(200);
        // EF Core 8 handles DateOnly natively with SQLite — no HasConversion needed
        builder.Property(h => h.Date).IsRequired();
        builder.Property(h => h.Year).IsRequired();
        builder.HasIndex(h => h.Year);
    }
}
```

## Entity Relationships

```text
HolidayYearRange (singleton Id=1)
    ← defines the valid year window

PublicHoliday (many rows)
    ← independent rows; Year field matches Date.Year
    ← no FK to HolidayYearRange (denormalized for simplicity)
```

There is no foreign key between `PublicHoliday` and `HolidayYearRange`. The year range governs
the UI display window; individual holiday rows may span any year. The Application layer enforces
that saved holidays fall within the configured year range (validation in
`SaveHolidayConfCommandHandler`).

## State Transitions

### Seeding (first run)

```text
[No HolidayYearRange row]
    → SaveHolidayConfCommand received
    → Handler detects missing row
    → Insert HolidayYearRange(Id=1, StartYear=currentYear, EndYear=currentYear+3)
    → Insert 9 Serbian seed PublicHoliday rows for currentYear
    → Process command normally (replace with command payload)
```

### Save (subsequent runs)

```text
[Existing HolidayYearRange row]
    → SaveHolidayConfCommand received
    → ExecuteDeleteAsync all PublicHoliday rows
    → InsertRange new PublicHoliday rows from command
    → Update HolidayYearRange row (StartYear, EndYear from command)
```

### Import (user-triggered)

```text
[User clicks Import, enters year Y]
    → ImportHolidaysFromWebCommand { Year = Y }
    → IHolidayImporter.ImportAsync(Y) fetches & parses web
    → Returns Result<IReadOnlyList<HolidayEntryDto>>
    → On Success: ViewModel Entries replaced (NOT saved to DB)
    → On Failure: ViewModel ErrorMessage set; Entries unchanged
```
