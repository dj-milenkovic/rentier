## Download and Updates

Download Rentier from [GitHub Releases](https://github.com/dj-milenkovic/rentier/releases): `Rentier-<version>-win-x64-setup.exe` or `-win-x64.zip` for Windows, `-osx-arm64.dmg` (Apple silicon) or `-osx-x64.dmg` (Intel) for macOS, and `-linux-x64.AppImage` for Linux. Every package updates itself from inside the app; packages of v1.3.0 and earlier do not and need a one-time switch.

See [Getting Started → Step 1](GETTING-STARTED.md#step-1--download-and-install) for installation, [Updates](GETTING-STARTED.md#updates) for how update notifications work, and [Switching from v1.3.0 or earlier](GETTING-STARTED.md#switching-from-v130-or-earlier).
