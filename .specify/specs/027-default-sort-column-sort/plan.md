# Implementation Plan: Default Sort & Column Sort for Filings and Reports

**Branch**: `feat/027-031-ux-improvements` | **Date**: 2025-07-24 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `.specify/specs/027-default-sort-column-sort/spec.md`

## Summary

Both the Filings and Reports tables must default to descending order by their most relevant date column (FilingDeadline for Filings, ImportDate for Reports) so the newest entries appear at the top without user interaction. The Filings DataGrid additionally gains interactive column sorting for all sortable columns. Sort direction is applied in the query/repository layer so it is consistent across all pages. The current ascending FilingDeadline sort is reversed to descending, a new `FilingSortColumn` enum is introduced, and both query records gain sort parameters with backward-compatible defaults.

## Technical Context

**Language/Version**: C# 12 / .NET 8

**Project Type**: Desktop application (Clean Architecture, CQRS)  
**Performance Goals**: N/A — sorting adds negligible overhead to existing queries

**Scale/Scope**: 2 tables affected (Filings paginated, Reports non-paginated), ~14 files changed/created

## Design Decisions (from research.md)

| # | Decision | Rationale |
|---|----------|-----------|
| R-001 | Use DataGrid `Sorting` event with `e.Handled = true` for server-side sort | Client-side sort only reorders visible page; query-layer sort required for multi-page correctness |
| R-002 | Add `FilingSortColumn` enum + `bool SortDescending` to `GetFilingsQuery` | Strongly-typed, compile-time safe, backward-compatible defaults |
| R-003 | Add `bool SortDescending` to `GetReportsQuery` | Minimal surface area for fixed-key sort |
| R-004 | Switch expression in repository for column mapping + `ThenBy(Id)` | Exhaustive at compile time; deterministic tie-breaker prevents row flickering |
| R-005 | Separate `ApplySortCommand` in ViewModel with page-reset rules | Clean separation from load command; traceable to FR-009/FR-010 |
| R-006 | Set `CanUserSortColumns="False"` on Reports DataGrid | Interactive sort not in scope for Reports; prevents confusing non-functional header clicks |
| R-007 | Use `Tag` property on DataGrid columns for sort-column identification | Lightweight metadata association; consistent with existing code-behind patterns |
